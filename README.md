# Consumer-and-Goods-Adhoc_Insights
SQL analytics project exploring Atliq Hardware’s sales, product performance, discounts, and channel contribution. Solved 10 business questions using joins, CTEs, window functions, and fiscal logic to deliver insights on customer behavior, product growth, sales trends, and revenue drivers.
The challenge uses multiple fact and dimension tables such as:

fact_sales_monthly

fact_pre_invoice_deductions

fact_gross_price

fact_manufacturing_cost

dim_customer

dim_product

Fiscal functions like get_fiscal_year() and get_fiscal_quarter() were used to perform time‑based analysis.

This project demonstrates skills in:

SQL joins

CTEs

Window functions

Aggregations

Fiscal logic

Business analytics

Insight storytelling
